# Yurt

Yurt runs real Linux userland (a shell, CPython, Jupyter, compilers) inside
WebAssembly sandboxes: in a browser tab, on the desktop, or as an isolated
workspace for AI agents.

**Try it:** [Yurt Playground](https://yurt-playground.pages.dev) boots a BusyBox
terminal, CPython and Jupyter entirely in your browser.

## Public repositories

- [yurt-playground](https://github.com/YurtOS/yurt-playground): the in-browser playground
- [nightmonkey](https://github.com/YurtOS/nightmonkey): JavaScript-to-WebAssembly compiler on SpiderMonkey
- [yurt-firefox](https://github.com/YurtOS/yurt-firefox): Yurt's SpiderMonkey patch queue
- [yurt-packages](https://github.com/YurtOS/yurt-packages): signed package repository for Yurt sandboxes
